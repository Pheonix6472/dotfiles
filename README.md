# dotfiles

Arch Linux desktop around the Mango compositor. Colors for most programs are generated by matugen from the current wallpaper.

## Contents

- `mango`: compositor config, binds and monitor rules
- `rofi`: launcher, power menu and a system menu
- `matugen`: templates for rofi, dunst, fastfetch, nvim, starship, spicetify, swaylock, zen and the sddm theme
- `fish`, `starship`, `fastfetch`, `btop`, `kitty`
- `nvim`: LazyVim with a matugen colorscheme
- `sddm`: login theme `matugen`
- `~/.local/bin`: `wallpaper`, `monitors`, `lock`, `shot`, `sddm-sync`, `sddm-profile`, `sysstat`, `nordvpn-toggle`

## Install

```sh
git clone https://github.com/Pheonix6472/dotfiles ~/dotfiles
cd ~/dotfiles
./install.sh --packages --system
```

Without flags only the user files are symlinked. Existing files are moved to `~/.dotfiles-backup`.
`--packages` installs `packages/native.txt` with pacman and `packages/aur.txt` with yay.
`--system` installs the sddm theme and config (needs sudo, adds your user to the `sddmtheme` group, log out afterwards).
Run `wallpaper /path/to/image` once to generate the colors.

## Notes

- Monitor names and positions in `home/.config/mango/config.conf` and `home/.local/bin/monitors` match my setup, adjust them first.
- `wallpaper` sets images through awww and videos through mpvpaper.
- `lock` runs swaylock.
- The zen profile path in the matugen config is detected by the installer.
- Spicetify and the Sleek theme are not included.
- `packages/optional.txt` lists tools that only single menu entries use.
- Generated files (colors, starship.toml, dunstrc and so on) are ignored by git.
